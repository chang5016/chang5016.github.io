# Facade attachments and suspension

Upper-floor windows, AC units and balcony slabs now follow the same footprint setback and podium height as their wall geometry. Balcony slabs sit at the floor datum instead of the next floor's ceiling. Ground-floor glazing no longer stretches the full office-building photograph across a shop window. Campus facades also use the separated ground/upper-floor atlas bands.

Front forks follow the same steering angle as the animated front wheel. The rear spring changes coil spacing without scaling its wire thickness. Front/rear load response uses bounded spring/damper integration with short substeps instead of simple interpolation; tests cover 25, 30, 60 and 120 FPS settling and recovery.

No original model/textures were reduced or replaced. This is an alignment and motion correction, not a newly sculpted scooter. Local build cannot run because dependencies remain unavailable; use the previously working source-build publication path. GPU visual acceptance and correspondence to the cover image are unverified.
