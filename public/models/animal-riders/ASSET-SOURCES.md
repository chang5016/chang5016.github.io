# Rounded articulated animal characters

"LowPoly Animal Characters" by Juggy: https://juggypuggy.itch.io/low-poly-animals

New downloaded bear, bunny and pig Blender characters, separate from the retained legacy Quaternius files. The original full meshes, smooth source surfaces, skin weights and materials are preserved. Source bone names are standardised and non-deforming hand/foot IK markers added for seated riding and driver contacts.

Author licence permits modified use in shipped personal/commercial games with attribution; forbids standalone asset-file redistribution/repackaging. Original Blender downloads are therefore retained outside the public project; the adapted GLBs are used as game resources. See LICENSE.txt and sources.json for licence, source hashes and exported-file hashes.

Conversion: `python scripts/import-animal-riders.py <downloaded-source-directory>` using Blender bpy 4.5.14. Inputs: bear.blend, bunny.blend, pig.blend and LICENSE_AnimalCharacters.txt, downloaded from the author's page. The same bear GLB is used for the metro operator and the Ferrari driver.
