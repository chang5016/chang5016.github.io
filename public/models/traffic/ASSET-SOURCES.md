# Traffic model sources

All models in this directory are used as optimized, reusable runtime GLB instances.

- `car.glb`, `taxi.glb`, `suv.glb`, `sports.glb`: Quaternius Cars Bundle, downloaded from Poly Pizza. Public Domain / CC0 1.0. https://poly.pizza/bundle/Cars-Bundle-FE5IWe6OMk
- `pug.glb`, `pig.glb`, `sheep.glb`, `llama.glb`: Quaternius Farm Animal Pack, downloaded from Poly Pizza. Public Domain / CC0 1.0. https://poly.pizza/bundle/Farm-Animal-Pack-1kUvRTPLzT
- `motorcycle.glb` and `Textures/colormap.png`: Kenney Starter Kit Racing. Included 3D assets are CC0. https://github.com/KenneyNL/Starter-Kit-Racing

The game caches each source model once and creates shared-geometry instances for moving traffic.
